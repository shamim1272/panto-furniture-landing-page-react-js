# 🪑 Panto — Modern Furniture Landing Page

A **modern, responsive, and elegant furniture eCommerce landing page** built with **React.js, Vite, and Tailwind CSS**. Panto features a clean premium design, interactive product browsing, cart management, theme switching, and a smooth testimonial experience.

## 🌐 Live Demo

🔗 **[View Live Demo](https://panto-furniture-landing-page-react-iota.vercel.app/)**

---

## ✨ Features

* 🎨 **Modern & Elegant UI**
  Clean, minimal, and premium design inspired by modern furniture and home décor.

* 📱 **Fully Responsive**
  Optimized for mobile, tablet, and desktop devices.

* 🛍️ **Interactive Product Showcase**
  Browse and filter products by categories such as:

  * 🪑 Chairs
  * 🛏️ Beds
  * 🛋️ Sofas
  * 💡 Lamps

* 🛒 **Shopping Cart Management**
  Add and manage products using React Context API with a dedicated `CartContext`.

* 🌗 **Dark / Light Mode**
  Switch between dark and light themes using `ThemeContext`.

* 🎠 **Testimonial Slider**
  Smooth and responsive testimonial carousel powered by **Swiper.js**.

* 💬 **Interactive UI Elements**
  Enhanced user experience with tooltips, notifications, and interactive components.

* 🚨 **SweetAlert2 Integration**
  Beautiful and user-friendly alerts for different actions.

* 🧭 **Multi-Page Navigation**
  Client-side routing implemented using **React Router DOM**.

## 🚀 Getting Started

Follow the steps below to run the project locally.

### Prerequisites

Make sure you have **Node.js v16 or higher** installed on your machine.

### 1. Clone the Repository

```bash
git clone https://github.com/shamim1272/panto-furniture-landing-page-react-js.git
```

### 2. Navigate to the Project

```bash
cd panto-furniture-landing-page-react-js
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

Or use the URL displayed in your terminal.

## 🧩 Key Concepts Used

### ⚛️ React Context API

Used for managing global application states such as:

* Shopping cart
* Theme preferences

### 🧭 React Router

Implemented client-side navigation between different pages without full-page reloads.

### 🎨 Tailwind CSS

Used utility-first CSS classes to create a responsive and maintainable UI.

### 🎠 Swiper.js

Used to create a responsive testimonial carousel with smooth transitions.
